🖥️ Método 3: Consola del Navegador

Para usuarios avanzados.

  1. Presiona F12 para abrir DevTools
  2. Ve a la pestaña "Console"
  3. Copia y pega este código:
const data = {}; Object.keys(localStorage) .filter(key => key.startsWith('bandcamp_listened_')) .forEach(key => { data[key] = JSON.parse(localStorage.getItem(key)); }); // Descargar como archivo const blob = new Blob([JSON.stringify(data, null, 2)], {type: 'application/json'}); const url = URL.createObjectURL(blob); const a = document.createElement('a'); a.href = url; a.download = 'browser_data.json'; a.click(); console.log('Exportado:', data);

🔄 Flujo de Sincronización

Una vez tengas el archivo exportado:

  1. Exporta localStorage (usando cualquier método anterior)
  2. Ejecuta el script de sincronización:
    python3 bc_sync.py --localStorage-file browser_data.json --interactive \ --folders "INBOX/Rock:Rock" "INBOX/Jazz:Jazz"
  3. Regenera el sitio:
    python3 bc_static_generator.py --input bandcamp_data_synced.json
  4. Sube los cambios:
    git add docs/ git commit -m "Sync: removed listened, added new" git push

🛠️ Herramientas Útiles

❓ Preguntas Frecuentes

¿Con qué frecuencia debo sincronizar?

Cuando quieras actualizar tu colección en el servidor. Por ejemplo, una vez al mes o cuando hayas escuchado muchos álbumes.

¿Pierdo mis datos al sincronizar?

No. El archivo JSON se actualiza, pero tu localStorage en el navegador NO cambia. Puedes hacer backup del JSON antes.

¿Qué pasa si dos dispositivos tienen diferentes estados?

Cada dispositivo tiene su propio localStorage. Exporta desde el que quieras como "fuente de verdad".

¿Puedo combinar datos de múltiples dispositivos?

Sí, pero requiere fusionar los archivos JSON manualmente o ejecutar el script varias veces.
